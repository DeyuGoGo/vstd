# 美術工單 (img_order)

此資料夾用來放遊戲內缺少的美術素材需求單。

## 使用方式

1. 每個工單一個資料夾，命名為 `編號_主題`（例：`001_blessing_gold`）
2. 資料夾內固定放兩個東西：
   - `SPEC.md` — 工單說明（規格、用途、參考、交付路徑）
   - `references/` — 風格參考圖（同系列現有作品）
3. 美術完工後，把產出的檔案放在 `SPEC.md` 中註明的「交付路徑」對應位置即可。
