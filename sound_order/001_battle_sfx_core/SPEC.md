# 工單 001 — 戰鬥核心音效 Pack

## 用途

目前整個遊戲完全沒有音效（`grep .ogg / .mp3 / .wav` 結果為零）。設計報告強調「打擊感」是割草遊戲是否「爽」的關鍵，而音效是其中 ROI 最高的元素——一個好的射擊+命中音可以瞬間把目前的「靜默畫面」拉到「在打遊戲」的層級。

本工單委託 9 種戰鬥核心情境音效，覆蓋一局戰鬥從開始到結算的所有關鍵時刻。配合既有的傷害數字、hit flash、螢幕震動，三者一起構成「打擊感三件套」。

## 風格基調

二次元日系奇幻 + 微科幻光感（看板娘武器是「星塵彈」，整體美術走暗紫魔法）。**避免**：

- 過度寫實的金屬撞擊音（會跟二次元立繪衝突）
- 過度卡通的 8-bit chiptune（風格不對）
- 過長尾音（射擊每 0.42s 一次，尾音不能蓋住下一發）

**推薦感覺**：可以參考《原神》戰鬥音效、《崩壞星穹鐵道》施法音效、《蔚藍檔案》的奇幻槍械音、《Dead Cells》部分魔法系武器命中音。輕魔法粒子 + 輕質感打擊。

## 規格

| 項目 | 值 |
|------|-----|
| **格式** | OGG Vorbis（首選）或 MP3 |
| **採樣率** | 22.05 kHz mono（或 44.1 kHz mono） |
| **位元深度** | 16-bit |
| **峰值音量** | -3 dBFS（同 pack 內相對響度要一致）|
| **交付路徑** | `app/public/audio/sfx/` |

## 音效清單（9 條）

| # | 檔名 | 情境 | 長度 | 風格描述 |
|---|------|------|------|---------|
| 1 | `sfx_hero_shoot.ogg` | 看板娘發射星塵彈 | 80–150 ms | 輕巧短促的「咻」+ 微星塵粒子尾音；連續觸發（每 0.42s）不能疊聲混亂 |
| 2 | `sfx_hit_normal.ogg` | 投射物命中敵人（一般） | 100–200 ms | 短促打擊感，半實體半光，類似「啪—吡」 |
| 3 | `sfx_hit_crit.ogg` | 投射物暴擊命中（18% 機率） | 200–350 ms | 比普通命中明顯更「重」+ 高頻金屬光澤點綴；有「這是暴擊」的識別度 |
| 4 | `sfx_hero_take_dmg.ogg` | 敵人衝到底部撞基地、看板娘扣血 | 250–500 ms | 低沉受擊衝擊 + 微金屬碎裂感，**避免**人聲（會讓不同國家玩家出戲）；可加微「陣痛/碎裂」氛圍 |
| 5 | `sfx_level_up.ogg` | 升級 modal 出現 | 700–1200 ms | 上揚 + 神聖光感的鈴音 + 短和弦；這是「正面回饋」最強烈的 0.5 秒 |
| 6 | `sfx_wave_clear.ogg` | 清完一波（升級前的微秒）| 200–400 ms | 短促正面提示（比 level up 內斂），可作為 level up 前奏 |
| 7 | `sfx_boss_spawn.ogg` | Boss 出場（wave 20）| 800–1500 ms | 低頻 sub bass + 詭異弦樂高頻共振；一聽就是「Boss 來了」的威壓感 |
| 8 | `sfx_game_over.ogg` | 戰敗 | 1500–2500 ms | 緩慢下行 + 失重感 + 微鐘聲尾韻；不要太悲，避免讓玩家不想再開一局 |
| 9 | `sfx_victory.ogg` | 勝利（boss 擊殺）| 1500–2500 ms | 三段式：擊倒 → 留白 → 揚升和弦；給玩家「我做到了」的爆發感 |

## 風格一致性

整個 pack 應該聽起來像「同一個遊戲的音效」，不是 9 段分頭做的素材：

- **頻率分佈**：建議 #1-#3（射擊/命中）以中高頻為主，#4-#7 中頻，#8-#9 低頻為主，整體頻譜覆蓋平衡
- **音色家族**：星塵粒子質感（高頻閃爍）+ 暖魔法低頻 + 輕金屬光澤；避免混入木頭、塑膠、機械齒輪等與世界觀衝突的音色
- **「壓抑感」克制**：戰敗音切勿太陰沉，本作整體調性偏奇幻冒險而非恐怖

## 交付方式

把 9 個 OGG 檔放到 `app/public/audio/sfx/` 對應檔名，並回報。工程整合會：

1. 建立 `app/src/audio/index.ts` 統一管理音效 API（preload、play、volume）
2. 在 [Battle.tsx](app/src/battle/Battle.tsx) 對應觸發點插入 `playSfx('hero_shoot')` 等呼叫
3. 加上 settings 面板的音量控制（後續工程，非本票範圍）
